About This Simulator

This dashboard runs a JavaScript re-implementation of the exact same four algorithms as the Python backend (FCFS, SJF, Priority, Round Robin) so you can generate and explore workloads instantly, without a server round-trip. For research records, run python main.py — it produces the same simulation plus a CSV/JSON/PDF report from the tested, canonical implementation. Load that JSON here via "Load JSON" in the sidebar any time.
